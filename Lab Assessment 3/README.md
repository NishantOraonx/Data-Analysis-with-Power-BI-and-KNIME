# Lab Assessment 3 – Titanic Survival Prediction Using KNIME

## Overview
Build a workflow-driven analytical system in KNIME to perform exploratory data analysis and automate analytical tasks using the Titanic passenger dataset.

## Objectives
- Import and clean the dataset
- Filter and summarize data
- Perform exploratory data analysis
- Explore data using charts and statistics
- Train a Decision Tree model
- Predict passenger survival
- Evaluate model accuracy
- Automate the workflow
- Export analytical results

## Dataset
Titanic Passenger Dataset.

## Tools Used
- KNIME Analytics Platform
- KNIME Analytics Platform nodes
- Decision Tree

## Workflow Sections
1. Prepare – Import, clean, and filter data
2. Explore – Statistics and visualizations
3. Model – Train Decision Tree and evaluate accuracy
4. Report – Export results and predictions

## Submission Files
- KNIME workflow (.knwf)
- LA3_Report.xlsx
- Predictions.csv
- Screenshots
- Report (.pdf)

## Insights
Key findings about passenger survival and the Decision Tree model will be documented here.
