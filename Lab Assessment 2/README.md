# Lab Assessment 2 – Netflix Data Analysis Dashboard

This lab focuses on data cleaning, data modelling, DAX, and interactive dashboard development using Power BI.

## Objectives
- Perform data cleaning using Power Query
- Build a data model
- Create relationships
- Write DAX calculated columns and measures
- Create KPI cards and visualizations
- Design charts, maps, and slicers
- Implement drill-through functionality
- Build an interactive dashboard

## Dataset
Netflix Movies and TV Shows dataset.

## Tools Used
- Microsoft Power BI Desktop
- Power Query
- DAX
